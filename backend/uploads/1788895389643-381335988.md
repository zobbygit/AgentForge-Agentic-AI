# BuildRadar — Full-Stack AI Developer Opportunity Intelligence Platform
```

```
You are an expert full-stack engineer and AI product architect.
```

```
Build a complete, production-quality web application called **BuildRadar**.
```

```
Create a polished, modern developer SaaS UI for BuildRadar with a premium dark-
first aesthetic, strong typography, clean layouts, subtle borders, meaningful
data visualizations, and restrained animations—avoid generic AI gradients,
excessive glassmorphism, oversized rounded cards, and anything that feels like
AI-generated template slop.
```

```
Make every page feel cohesive and production-ready, with excellent spacing,
hierarchy, loading/empty/error states, intuitive navigation, and clear
interactions across the landing page, dashboard, trends, opportunities,
workspace, and admin dashboard.
```

```
Make the entire experience fully mobile responsive and touch-friendly, adapting
tables, charts, cards, navigation, forms, and admin interfaces properly for
small screens rather than simply shrinking the desktop layout.
```

```
BuildRadar is an **AI-powered technology trend → project opportunity
intelligence platform**. It continuously analyzes public developer ecosystem
signals and turns emerging trends into concrete, evidence-backed project
opportunities for developers.
```

```
The goal is NOT to build another news aggregator or generic AI project
generator.
```

```

```

```
**GitHub + Hacker News + arXiv + RSS + Open-source releases**

### Free Model Handling
```

```
Do NOT hardcode the entire application around one permanent model ID.
```

```
Implement logic that can:
```

`1. Retrieve available OpenRouter models.` 

`2. Identify models that are genuinely free.` 

`3. Select an appropriate free model for the task.` 

`4. Attempt another free model if the selected model fails.` 

`5. Never select a paid model.` 

`6. Handle rate limits and temporary failures gracefully.` 

```
Use a model-selection strategy based on the task where possible.
```

```
For example:
```

```
```text
Trend Analysis
      ↓
Available OpenRouter Free Models
      ↓
Select suitable free model
```
```

```
and:
```

```
```text
Architecture Generation
      ↓
Available OpenRouter Free Models
      ↓
Select suitable free model
```
```

```
If OpenRouter free models are temporarily unavailable:
```

```
```text
"No OpenRouter free AI models are currently available.
Please try again later."
```
```

```
Do NOT fall back to another AI provider.
